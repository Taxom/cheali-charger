# Taxom: iMAX B6 50W на ATmega32

Эта ветка основана на `gromdar/cheali-charger`, коммит
`382229dde21bc51701474fbfae0461fbd61eb104` от 1 мая 2026 года.
Он включает все изменения `stawel/cheali-charger` до текущего коммита
`3afe8f4f3ff715be109fd8decf7fc0201e4e7d30` от 10 июля 2024 года и четыре
дополнительных коммита апреля–мая 2026 года для Pb/AGM.

## Аппаратная конфигурация

Собирается только `imaxB6-original` на ATmega32 с кварцем 16 МГц:

| Параметр | Предел |
| --- | --- |
| Заряд | 50 Вт, до 5 А |
| Разряд | 5 Вт, до 1 А |
| Балансировка | До 6 банок |
| Flash / SRAM / EEPROM | 32768 / 2048 / 1024 байт |

Ток одновременно ограничивается заданным током и мощностью.
Вариант `original` обозначает аппаратную конфигурацию проекта.
Для экземпляра владельца по фото установлены ATmega32-16AU, 74HC4051,
LM324/LM2904 и кварц 16 МГц; владелец указал шунты 0,05 и 0,5 Ом.
Фактическое усиление аналоговых цепей и точность измерений ещё предстоит
проверить при калибровке. Параметры 80-ваттной конфигурации не используются.

## Pb/AGM

Сохранены тип AGM и программа `float charge` из gromdar.
Алгоритм float в этой ветке не изменён. Актуальная реализация переключается
между CC, паузой стабилизации 10 секунд, CV и ожиданием перед повторным циклом.
Старая документация gromdar описывает предшествующий вариант с алгоритмом
Тевенина; последняя версия использует отдельный регулятор в `PbFloatStrategy.cpp`.

Минимальный заданный ток float может опускаться до 10 мА. Возможность B6
фактически поддерживать такой ток зависит от аналоговой части и калибровки;
поведение CV и отключения необходимо проверить внешними приборами.
Порог напряжения следует выбирать по документации конкретного аккумулятора.
Аппаратных испытаний на экземпляре владельца пока не было.

## Версия и сохранённые профили

Прошивка и формат EEPROM сохранены как в gromdar: `2.02`, `e10.3.12`.
Код зарядки, номера химий и обработка сохранённых данных не изменены.
Для этого экземпляра планируется первая установка с полной очисткой EEPROM
и последующим `reset default`, поэтому перенос старых профилей cheali
не выполняется. Если в будущем потребуется перенос профилей со старых
веток cheali, совместимость формата следует проверить отдельно.

На исходном заряднике прочитаны сигнатура `1E 95 02`, lock `C0`,
LFUSE `2F`, HFUSE `C9`. Пробное чтение вернуло адресные шаблоны.
Рабочей резервной копии заводской прошивки и EEPROM нет.
Снятие этой защиты через Chip Erase удалит Flash и EEPROM.
Первоначальная установка требует полной калибровки; фьюзы 2F/C9 подходят
для первоначального запуска и в этом плане не меняются.

## Сборка

На Ubuntu 24.04:

```sh
sudo apt-get update
sudo apt-get install -y cmake make gcc-avr binutils-avr avr-libc python3
python3 scripts/build_b6_50w.py
```

Перед обычной сборкой изменения должны быть закоммичены. Для проверки
незакоммиченных правок есть `--allow-dirty`; такие образы помечаются `dirty`.
Дата внутри прошивки берётся из времени коммита через `SOURCE_DATE_EPOCH`.

Результаты находятся в `dist/b6-50w`: HEX, BIN, ELF, `manifest.json`
и `SHA256SUMS`. Скрипт проверяет преобразование HEX обратно в BIN,
контрольные суммы Intel HEX средствами avr-objcopy, наличие строк Pb/AGM,
а также размеры Flash, статической SRAM и EEPROM. Остаток SRAM в отчёте
предназначен для стека; его фактический максимум требует проверки на устройстве.
GitHub Actions выполняет ту же сборку и сохраняет артефакты на 90 дней.

Готовые старые файлы в `hex/` унаследованы из основного проекта и не содержат
наши изменения. Для этой ветки используют свежий HEX из `dist/b6-50w`
или артефакт её успешной сборки GitHub Actions.

## Первый запуск

После записи HEX требуется `options -> reset default`, затем калибровка
входного напряжения, напряжения аккумулятора и используемых балансировочных
каналов по мультиметру. Для токов в архитектуре 50W предусмотрены точки:

| Режим | Точки калибровки |
| --- | --- |
| Заряд | 100 мА и 1000 мА |
| Разряд | 100 мА и 300 мА |

Амперметр включают последовательно с аккумулятором. После калибровки
проверяют малые токи, завершение заряда, балансировку и разряд с независимым
контролем напряжений. Экспертная калибровка первых двух банок требует
отдельной проверки схемы.

Во время ISP-программирования сетевой вход, внешний DC-вход и аккумуляторы
отключены; логическую шину питают стабилизированными 5 В.
При обычной работе сначала подают питание зарядника, затем подключают
аккумулятор; отключают в обратном порядке.
